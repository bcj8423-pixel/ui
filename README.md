# AI 사용-유능성 실험 프로토타입

요청하신 4단계 실험 패러다임(기저선 → 조작 → 예측/전이 → 행동적 의존)을 브라우저에서 동작하는 단일 페이지 프로토타입으로 구현했습니다.

## 실행

```bash
python3 -m http.server 4173
```

브라우저에서 `http://localhost:4173` 접속.

## 구현된 핵심 요소

- 집단 간 무선할당(통제 / 정적 AI 정보 / 상호작용 AI)
- 1단계 기저선 6문항(외부 도움 없음)
- 2단계 조작 10문항(집단별 AI 조작)
- T1 BPNSFS 유능성 하위척도(충족 4 + 좌절 4, 문항 순서 무선화)
- 3단계 예측 질문 + 전이 10문항(AI 인터페이스 제거)
- T2 BPNSFS 재측정
- 4단계 전원 동일 AI 접근권 + 1분 시연 + 행동적 의존 지표 수집
  - AI 호출 빈도
  - 첫 AI 호출 잠복시간
  - AI 미사용 완료 문항 비율
- 분석용 JSON 내보내기
